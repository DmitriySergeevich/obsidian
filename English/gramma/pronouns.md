**subject pronouns** - I, you, he, she, it, we, they. Местоимение подлежащее. Заменяет существительное-подлежащее

**object pronoun** - me, you, him, her, it, us, them.
Местоимение объект. Заменяет существительное-дополнение. Служит для обозначения объекта, на который направленно действие. Используется после предлога

**possessive adjective** - my, your, his, her, its, our, their.
Служит для указания принадлежности существительного кому-либо. Используется только с существительным.

**possessive pronoun** - mine, yours, his, hers, its, ours, theirs. Служит для указания принадлежности кому то, но без указания самого предмета. 

**Местоимение Whose** - используется для вопроса о принадлежности чего-то кому-то. Используется в конструкциях 
Whose + be или Whose + существительное + verd.
